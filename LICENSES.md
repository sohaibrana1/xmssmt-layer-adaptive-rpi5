# Licensing and Attribution

This reproducibility repository contains source code and research artifacts with different licensing and attribution requirements.

## XMSS/XMSSMT source

The source under:

`source_xmssmt/heterogeneous/`

retains the original license and attribution terms of the underlying XMSS/XMSSMT implementation.

The original license file is preserved as:

`source_xmssmt/heterogeneous/LICENSE`

The experimental modifications used in the associated manuscript include support for:

- heterogeneous per-layer tree heights
- heterogeneous per-layer WOTS+ Winternitz parameters
- FAST/BDS traversal with asymmetric layer allocation
- serialized secret-key state accounting
- rollover validation

The experimental configurations are not standardized XMSSMT parameter sets and are not assigned standardized OIDs.

## Research artifacts

Analysis scripts, processed datasets, figures, manifests, provenance records, supplementary files, and reproducibility documentation are included for scientific reproducibility.

Users should cite the associated manuscript and archived reproducibility release when available.
